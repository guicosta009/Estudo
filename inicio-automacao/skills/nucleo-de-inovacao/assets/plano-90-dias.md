## Semana a semana

| Semanas | Foco | Tarefas | Responsável | Entrega | Feito em |
|---|---|---|---|---|---|
| 1 | Nomear e tirar a foto | Assinar o termo; rodar o diagnóstico; escrever o código v0; confirmar o setor-alvo | | Termo assinado, nota, código v0, setor-alvo | |
| 2 | POP do setor-alvo | Escrever o POP v1 com S, A e H; nomear os embaixadores | | POP v1, embaixadores | |
| 3 e 4 | Base, política e funil | Montar o Projeto no Claude com código, POP e modelos; escrever e assinar a política v1; abrir o funil e pontuar as primeiras fichas | | Projeto montado, política assinada, matriz | |
| 5 | Preparar a primeira automação | Marcar o checklist de prontidão; separar 3 a 5 casos de teste anonimizados; conferir a conta profissional; fechar a linha de base; escolher a ideia nº 1; combinar quem cobre o escritório no tempo de construção | | Prontidão marcada, casos de teste, conta conferida, linha de base | |
| 6 | Construir e ligar a primeira automação | Desenhar e instalar a automação; testar com os casos; ligar com revisão humana; refazer o diagnóstico | | Primeira automação rodando, segunda nota | |
| 7 e 8 | Uso de verdade | Colocar a automação dentro do POP vigente; treinar o setor; manter a revisão obrigatória; montar o primeiro painel mensal | | Automação no POP, setor treinado, painel | |
| 9 e 10 | Segunda ideia e segundo setor | Pilotar a segunda ideia "Faça agora"; atualizar o POP | | Segundo piloto, POP v2 | |
| 11 | Arrumar a casa | Limpar a base (duplicatas, versões velhas, sem dono); fechar a lista de prompts oficiais | | Base limpa, prompts oficiais | |
| 12 e 13 | Primeira revisão trimestral | Refazer o diagnóstico; revisar POPs, código, política e ferramentas; planejar o próximo trimestre; decidir o tamanho do núcleo para o próximo ciclo | | Terceira nota, plano do próximo trimestre | |

Se a base atrasar e não ficar pronta nas semanas 3 e 4, o Projeto é montado na semana 5, junto com a prontidão.

As semanas 7 e 8 são onde muita automação morre: a novidade passa, a revisão começa a ser pulada e o jeito antigo volta. Nessas duas semanas, o placar da semanal olha primeiro se a revisão está acontecendo.
